1. Problem framing and workflow

Is predicting whether a basketball shot is made a binary-classification problem? What evaluation metrics are most appropriate if the required output is a probability rather than a hard class label?

Should I begin with logistic regression as a baseline, and what other models should I consider for nonlinear relationships and interactions among numerical and categorical basketball features?

Should I create the train and validation split before exploratory analysis? How can I avoid allowing validation-set observations to influence feature selection and modeling decisions?

2. Data validation and cleaning

Write Python checks for a dataframe named full_train_csv covering shape, column types, missingness, duplicates, target balance, numeric ranges, categorical cardinality, and possible train-validation leakage.

The closestdefapproach field contains string representations of dictionaries with four time-indexed values. How can I safely parse each entry, validate the keys and numeric values, identify malformed records, and expand the values into separate columns?

How should I distinguish between the closest defender and a contester in this dataset? Which variables describe general defensive proximity, and which describe an officially recorded contest?

Some locationx and locationy values appear inconsistent with normal court coordinates. How should I evaluate whether they represent legitimate full-court shots, coordinate-system behavior, or data errors?

Only 78 records have a material discrepancy between their recorded distance and the distance implied by their coordinates. Should I remove them, set their coordinates to missing, or retain them? What are the tradeoffs when the affected share is extremely small?

How should I handle contester fields with very high missingness? Should missing values be interpreted as no additional contester, unknown information, or ordinary missing data?

3. Exploratory data analysis

How should I structure EDA for this binary target? Which target-versus-feature plots are useful for continuous, categorical, spatial, and high-cardinality variables?

Which variables should receive the most attention when modeling shot make probability: distance, shot type, court location, closest-defender distance, number of contesters, defender approach, shot clock, dribbles, shooter speed, game state, player identity, team, and season?

How should I interpret make-rate curves when the number of observations becomes very small in extreme distance or defender-separation bins?

Shooter speed appears associated with make rate overall, but the relationship changes after conditioning on shot type. Is this likely an example of confounding or a composition effect, and how should it influence feature selection?

Defenders classified as rapidly closing do not always correspond to lower make rates than stationary defenders. What other variables could explain this pattern, and why should the relationship not be interpreted causally?

Review the EDA tables and graphics and identify which findings support including or excluding each feature family. Focus on predictive usefulness, leakage risk, missingness, sample size, and interactions.

How can I preserve the distinction between missing contester information and a true zero-contester shot while still creating useful count, minimum-distance, and mean-distance summaries?

Which fields should CatBoost receive as categorical features rather than numeric codes? How should I treat shooter, closest defender, teams, season, month, shot type, and game state?
